# Hi, I'm Eli Chao (Zijian Cao)

I build inventory tools, office systems and AI support workflows for small and midsize businesses. I work through the whole delivery: talking with users, mapping how the job gets done, building and testing the system, and training the people who will use it.

I'm based in Jiaxing, China (UTC+8), and work remotely. I began working in B2B export sales in 2017 and have nine years of experience in that field. I've spent three years building software with an AI-assisted workflow, using tools such as Codex, Claude Code and Cursor.

## Start here

- **LendLoop** — A neighbourhood tool-lending board built with Next.js, TypeScript, Clerk, Convex and n8n. The repo shows how signed webhook callbacks keep retries from recording the same notification twice. [See the code and walkthrough](https://github.com/eli-ovops/lendloop)
- **Furniture inventory** — I led delivery of a warehouse tool that tracks stock by carton. I built protection against duplicate submissions, reversible corrections and checks that keep stock counts consistent. [Read the case study](https://github.com/eli-ovops/case-furniture-scan-inventory)
- **RAG customer support** — On a team delivery for a water purification brand, I organised the knowledge base, configured retrieval and tested the answers. The write-up shows two test answers from the public widget and how they compare with the published FAQ. [See the tested answers](https://www.eliai.cn/en/cases/p36.html)
